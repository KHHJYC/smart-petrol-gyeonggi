# 스마트펫트롤 · 우리동네 안전지킴이

경기도 공공데이터로 CCTV·보안등을 탐색하고, 반려견과 산책하며 시설 상태를 관찰·기록하는 공모전 웹 프로젝트입니다. 기존 다른 프로젝트와 독립된 GitHub Pages 배포본입니다.

## 웹에서 할 수 있는 일

- 31개 시군 선택, 동네·주소 검색, CCTV 목적 필터, 지도 표식 상세 조회
- CCTV·보안등이 주변보다 적게 등록된 약 250m 구획을 노랑~주황 그라데이션으로 확인
- 시설 점검 후보 위치 목록과 지도 이동, 선택 위치의 반경별 시설 수와 직선거리
- 카카오맵·네이버지도·구글맵과 로드뷰로 선택 장소 확인
- 반려동물 등록 통계, 조명 종류와 전력 구간별 설치 개소 수, 조명 연구 근거
- 순찰 시간 측정, 현장 기록, 확인 근거와 상태 변경, JSON·CSV 및 인쇄/PDF 출력

**기록은 현재 브라우저에 저장됩니다.** 서버로 전송되지 않으며, 계정 간 공유·기기 간 동기화를 제공하지 않습니다. 브라우저 데이터를 지우기 전에 내려받기로 보관하세요. 공식 신고는 안전신문고에서 별도로 제출합니다.

## 실행과 빌드

Node.js 22.13 이상에서 `npm ci` 후 다음을 실행합니다.

```sh
npm run check
npm run lint:app
npm test
npm run build:pages
npm run test:pages
```

배포 대상은 `site-static/`입니다. 앱 코드는 분할하고, 공공데이터는 지역별 gzip 파일로 압축해 모바일 다운로드를 줄였습니다. 최신 Chrome·Edge·Safari가 필요합니다. 배경지도에는 인터넷 연결이 필요합니다.

`npm run dev`와 `npm run build`는 별도로 보존한 서버형 원본을 위한 명령입니다. 서버형 원본의 `/api/records`와 D1·플랫폼 인증은 GitHub Pages에서 실행되지 않습니다. 서버형을 다른 호스팅으로 옮기려면 검증된 로그인과 DB를 연결해야 합니다. 기존 Sites 프로젝트 ID는 이 저장소에서 제거했습니다.

## API와 매일 갱신

GitHub Actions 비밀값 `GG_API_KEY` 한 개를 네 API에 사용합니다.

| 자료 | API 서비스명 |
| --- | --- |
| CCTV 위치 | `CCTV` |
| 보안등 위치 | `SECRTLGT` |
| 반려동물 등록 | `AnimalRegistStus` |
| 시군 보안등 종류별 집계 | `Secrtlgt` |

`SECRTLGT`와 `Secrtlgt`는 대소문자가 다른 별개 자료입니다. API 키는 HTML·공개 소스·로그에 넣지 않습니다.

`Publish Smart Petrol` 작업은 소스 갱신, 수동 실행, 매일 한국시간 오전 6시에 작동합니다. 전체 페이지 수집 → 데이터 정리 → 점검 후보 계산 → 검사 → 공개 파일 빌드 → 배포를 순서대로 수행합니다. 어느 단계든 실패하면 배포하지 않아 기존 사이트가 유지됩니다. 예약 실행은 GitHub 사정으로 지연되거나 누락될 수 있습니다.

수집한 최신 자료는 그 실행의 배포 파일과 7일 보관 자료에 들어가며 소스 저장소에 자동 커밋하지 않습니다. 따라서 저장소에 포함된 초기 자료와 현재 웹에 게시된 자료의 확인 시각은 다를 수 있습니다. 수동 실행의 `refresh_data=false`는 포함된 초기 자료로 재배포하는 복구 옵션이므로 일반 갱신에는 사용하지 마세요.

기존 AI 검토 메모는 원본 확인 시각이 같은 경우에만 표시합니다. 데이터가 갱신되면 오래된 메모를 숨깁니다. 자동 갱신 작업이 생성형 AI를 새로 호출하거나 범죄를 예측하지 않습니다.

## 해석과 출처

지도 그라데이션은 주변 8구획과 비교한 **등록 시설의 상대 부족 지표**이며, 검증된 범죄위험이나 실제 어두움의 지표가 아닙니다. 불충분한 지역 자료는 분석에서 제외하며 누락을 안전함으로 해석하지 않습니다. 실제 밝기·작동 상태·촬영 범위·보행 가능성은 현장 확인이 필요합니다.

조명 집계는 전력 구간별 개소 수이며 조도나 전기 사용량이 아닙니다. 노란빛만으로 노후·범죄위험을 판단하지 않습니다. 반려동물 수는 실제 순찰 참여자 수가 아닙니다.

공공자료: [경기데이터드림](https://data.gg.go.kr/). 배경지도: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). 활동 이미지: 사용자가 제공한 스마트펫트롤 제안서의 이미지. 데이터와 이미지 등 제3자 자료의 권리는 각 출처에 있습니다. 조명 연구 원문은 웹 화면과 `조명자료_사실검증.md`에서 확인할 수 있습니다.

GitHub 설정은 `GITHUB_이전전_안내.md`, 검증 범위는 `VALIDATION.md`에 기록했습니다.
